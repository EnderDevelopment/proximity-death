# ProximityDeath

ProximityDeath is a Minecraft plugin that enhances the death message system by restricting visibility to players within a 500-block radius. This plugin ensures that only players nearby can see the death message of another player, adding a layer of realism and immersion to your Minecraft server.

## Install

1. Download the ProximityDeath plugin JAR file from the releases section.
2. Place the JAR file into the `plugins` folder of your Minecraft server.
3. Restart or reload your server to load the plugin.

## Use

1. Once the server is running with the ProximityDeath plugin, players will automatically see death messages only if they are within 500 blocks of the deceased player.
2. No additional configuration is required. The plugin works out of the box.
